# 구현 결정 기록

기획서(`GAME_DESIGN_v0.1.md`)의 **[확정]** 규칙은 바꾸지 않는다. 구현하면서 정한 **[MVP 제안] · [튜닝] · [추후 결정]** 의
임시안과 해석만 여기에 남기고, 플레이 테스트로 바뀌면 같은 줄을 고치거나 새 줄을 더한다.
튜닝 숫자 자체는 `resources/*_tuning.gd` 의 기본값과 주석이 기준이다.
